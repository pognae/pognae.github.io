자주 묻는 질문

문의 메일로 가장 자주 받는 질문을 모았습니다. 답변은 앱이 실제로 동작하는 방식과 같게 적었습니다. 더 궁금한 점은 문의 페이지의 메일로 보내 주세요.

무료인가요?

무료입니다. 회원 등급도, 결제 화면도, 체험 기간도 없습니다. 서버를 두지 않아 유지 비용이 거의 들지 않고, 그 비용은 페이지에 붙는 광고로 충당합니다. 기능을 유료로 나눌 계획은 지금은 없습니다.

광고를 차단한 브라우저에서도 모든 기능이 똑같이 동작합니다. 광고를 보지 않으면 수익이 줄 뿐, 기록이나 백업에 제한이 생기지는 않습니다.

회원가입이 필요한가요?

필요하지 않습니다. 앱을 열면 바로 오늘 날짜의 편집기가 나옵니다. 이메일 주소를 받지 않고, 비밀번호를 만들지 않으며, 로그인 상태를 저장하지도 않습니다. 그래서 계정을 잃어버릴 일도, 비밀번호를 재설정할 일도 없습니다.

대신 기기를 구분하는 수단이 없으므로, 같은 브라우저에서만 기록이 이어집니다. 브라우저를 바꾸면 이전 기록이 보이지 않는 이유입니다.

기록은 어디에 저장되나요?

이용자의 브라우저 안에만 저장됩니다. 기본은 브라우저의 localStorage이고, 3year-diary:v1:entry:로 시작하는 키에 날짜별로 들어갑니다. 설정으로 IndexedDB를 쓸 수도 있습니다. 어느 쪽이든 서버로 전송되는 일은 없으며, 개발자도 내용을 볼 수 없습니다.

브라우저 개발자 도구의 Application 탭에서 저장된 값을 직접 확인할 수도 있습니다. 다만 내용을 직접 고치면 형식이 깨져 앱이 읽지 못할 수 있으니, 수정은 앱 안에서 하시길 권합니다.

기기를 바꾸면 기록이 따라오나요?

자동으로는 따라오지 않습니다. 브라우저 저장소는 기기마다 따로이기 때문입니다. 이전 기기에서 JSON 백업을 내려받아 새 기기의 도구 → 백업 가져오기로 불러오면 그대로 옮겨집니다. 파일은 메일이나 드라이브로 옮기면 됩니다.

가져오기를 누르면 총 건수와 겹치는 기록 수가 먼저 표시됩니다. 새 기기라면 병합을 선택하면 되고, 두 기기에 나눠 쓴 기록이 있다면 양쪽을 각각 내보낸 뒤 한쪽에서 병합하면 됩니다.

백업은 어떻게 하나요?

상단 도구 메뉴에서 JSON 백업 내보내기를 누르면 diary-backup-YYYYMMDD.json 파일이 내려받아집니다. 주 1회, 일요일 저녁처럼 요일을 정해 두면 잊지 않습니다. 파일에는 날짜별 내용과 마지막 수정 시각이 들어 있어 나중에 병합할 때 기준으로 쓰입니다.

백업 파일은 구글 드라이브나 메일로 한 부 더 보관하시길 권합니다. 기기 안에만 두면 기기를 잃었을 때 함께 사라집니다. 마크다운이나 CSV로도 꺼낼 수 있지만, 다시 가져오는 용도로는 JSON이 가장 정확합니다.

여러 기기에서 같이 쓸 수 있나요?

동시에 쓰는 기능은 없습니다. 서버가 없어서 자동 동기화를 하지 않습니다. 휴대폰과 노트북에서 각각 쓰고 있다면, 한쪽에서 내보내고 다른 쪽에서 가져오는 방식으로 맞출 수 있습니다. 병합은 수정 시각이 더 최신인 기록만 덮어쓰므로 양쪽에 있는 기록이 사라지지는 않습니다.

같은 날짜를 두 기기에서 다르게 고쳤다면 마지막으로 저장한 쪽이 남습니다. 두 내용을 모두 살리고 싶다면 가져오기 전에 한쪽 내용을 다른 날짜에 임시로 적어 두는 편이 안전합니다.

광고는 왜 나오나요?

서비스 운영비를 광고로 충당합니다. 광고는 Google AdSense를 통해 게재되며, 광고 영역은 본문과 편집기 바깥에만 둡니다. 입력 중인 블렛 안에는 광고를 넣지 않습니다. 광고를 누르도록 유도하는 배치나 자동 클릭 코드는 넣지 않았습니다.

승인 전에는 광고 자리를 비워 두고 아무것도 표시하지 않습니다. 승인 이후에도 광고 차단 프로그램을 쓰고 있다면 광고가 보이지 않을 수 있습니다.

개인정보를 수집하나요?

일기 내용을 포함해 서버로 보내는 개인정보는 없습니다. 이름, 전화번호, 이메일을 요구하지 않고 분석 도구도 넣지 않았습니다. 다만 광고를 게재하는 Google이 쿠키를 사용할 수 있고, 호스팅 사업자인 GitHub가 접속 기록을 남길 수 있습니다. 자세한 내용은 개인정보처리방침에 적어 두었습니다.

맞춤 광고를 원하지 않으시면 Google 광고 설정에서 끌 수 있습니다. 쿠키를 모두 차단해도 앱은 정상적으로 동작합니다.

오프라인에서도 되나요?

한 번 페이지를 연 뒤에는 대부분 동작합니다. 기록은 브라우저 안에서 읽고 쓰기 때문입니다. 다만 페이지 자체를 처음 여는 것과 광고 표시에는 인터넷이 필요합니다. 비행기나 지하철에서 쓰실 때는 미리 한 번 열어 두시면 편합니다.

홈 화면에 추가해 두면 앱처럼 열립니다. 오프라인 전용으로 설계한 앱은 아니라서, 브라우저가 페이지를 새로 받으려 하면 연결 오류가 날 수 있습니다. 그때는 저장 배지가 아니라 편집기 아래 저장 버튼을 눌러 두세요.

기록을 지우려면 어떻게 하나요?

해당 날짜를 연 뒤 이 날짜 기록 지우기를 누르면 그날 기록만 삭제됩니다. 전체 기록을 지우려면 브라우저 설정에서 이 사이트의 저장 데이터를 삭제하면 됩니다. 지운 기록은 되돌릴 수 없으므로, 지우기 전에 JSON 백업을 받아 두시길 권합니다.

브라우저의 인터넷 사용 기록 삭제와 사이트 데이터 삭제는 다릅니다. 기록 삭제는 후자에서 이루어지며, 전자만 지웠다면 일기는 남아 있습니다.
