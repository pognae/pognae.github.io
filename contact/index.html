문의 메일

imaxaug@gmail.com으로 보내 주세요. 제목에 [3년 다이어리]를 붙여 주시면 놓치지 않고 찾기 쉽습니다. 영업일 기준 3일 안에 답장드리는 것을 목표로 하고, 버그 제보는 확인되는 대로 먼저 회신드립니다.

3년 다이어리는 개인이 광고 수익으로 운영하는 무료 기록 도구이고, 일기 내용은 서버로 전송되지 않아 제가 열람할 수 없습니다. 그래서 문의에는 일기 원문 대신 상황 설명만 적어 주셔도 충분합니다.

주말이나 연휴에 보낸 메일은 다음 영업일에 확인합니다. 답장이 오지 않았다면 스팸함을 한 번 확인해 주세요.

버그 제보에 적어 주시면 좋은 것

다음 네 가지가 있으면 원인을 훨씬 빨리 찾을 수 있습니다.

  • 사용한 기기와 브라우저(예: 갤럭시 S22, 크롬)
  • 문제가 생긴 날짜와 하려던 동작(예: 붙여넣기, 날짜 이동, 백업 가져오기)
  • 화면에 표시된 저장 배지 상태(변경됨·저장 중·저장됨·저장 실패)
  • 가능하면 화면 캡처. 일기 내용이 담겨 있다면 가린 뒤 보내 주세요

기록이 사라진 것 같다는 문의에는 저장 배지 상태와 사용한 브라우저를 꼭 적어 주세요. 대부분의 경우는 다른 브라우저에서 열었거나 시크릿 모드로 열어 저장 위치가 달라진 경우입니다. 브라우저를 바꾸지 않았다면, 사이트 데이터 삭제 여부와 기기 저장 공간도 함께 확인해 주세요.

기능 제안과 광고 문의

기능 제안은 "어떤 상황에서 무엇이 불편한지"를 중심으로 적어 주시면 판단이 빠릅니다. 구현 여부와 시기는 정해 두지 않았지만, 백업과 데이터 보존에 관한 제안을 우선 검토합니다.

광고 게재 위치나 정책에 관한 문의도 같은 메일로 받습니다. 광고 내용 자체에 대한 신고는 Google 광고 신고 절차를 함께 이용해 주시면 더 빠르게 처리됩니다.

메일에 적지 말아야 할 것
